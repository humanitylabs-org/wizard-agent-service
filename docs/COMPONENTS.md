# Agent Service component inventory

The shell/app UI inventory remains in wizard-ux `docs/COMPONENTS.md`.
This repository adds no front-end implementation. Its reusable back-end components
are listed here so new capabilities have an explicit owning module rather than
being copied into apps or runtime-specific forks.

| Capability | Entry points | Reuse and verification |
| --- | --- | --- |
| Hermes history schema admission | `schema_version` / `require_supported` (`ops/agent-runtime/history_schema.py`) | NEW shared stopped-history metadata reader; EXTEND the existing home/archive and restricted importer admission, REUSE the frozen runtime lock and journal/undo. Refuses unknown/newer schemas and nonempty recovery sidecars without opening a source SessionDB or migrating/checkpointing it. No UI component or runtime fork. Covered by `tests/test_history_schema.py`, `tests/test_restricted_import.py` and the importer scan/refusal contracts; see `ops/agent-runtime/HISTORY_SCHEMA.md`. |
| Released app workflow guard | `pre_tool_call` / `register` (`hermes-plugin/wizard-os/app_skill_guard.py`) | EXTEND the existing stock-Hermes `wizard-os` plugin hook registration; REUSE `kernel.os_home()` / `read_registry()` and App Manager's skills mount. Blocks private/installed app-skill mutations without copying app workflows into the agent. Optional shadow migration list defaults empty. Covered by `tests/test_app_skill_guard.py` through the real plugin registration; see `docs/app-skill-guard.md` for scope and limits. |
| Owner phone metadata | `createDevices` / `devicesTool` (`server/devices.mjs`), `GET /wizard/v1/devices` | NEW bounded phone registry; EXTEND the owner-authenticated shell proxy and gateway builtins. Reuses the existing Android diagnostics POST, stores only allowlisted model/app/WebView metadata (never events or accessibility services), caps at 20 and throttles atomic writes. Covered by `tests/devices.test.ts` and `tests/devices-http.test.ts`. |
| Supervisor review ledger and Reporter checker | `Supervisor` (`server/supervisor.mjs`), `lintReport` (`server/reporter.mjs`), `installSupervisorAssets` (`server/supervisor-assets.mjs`) | Reuses durable run admission and scheduler delivery/readback; all four runtimes use the same service and supported Hermes adapter. Private/siloed callers refuse. Covered by Supervisor/Reporter suites and `supervisor-reporter` in the agent acceptance matrix. |
| Heavy result ownership, delivery notices and completion-status guard | `DurableHeavyQueue` (`server/heavy-queue.mjs`), `createHeavyIntegration` (`server/heavy-integration.mjs`), `guardHeavyStatus` (`server/thread-status.mjs`) | Reuses the existing run queue, per-job SQLite JSON records and shared main/routed presentation. Heavy siblings and automatic retries share an owner generation; owner steering still fences them. Dropped results become context on the next successfully dispatched turn. All four runtime kinds are covered by `tests/heavy-status.test.ts`; ancestry and restart by `tests/heavy-continuation-admission.test.ts`. |
| Agent-owned helper and Supervisor wait projection | `readSupervisorBuildWaits` (`server/supervisor-wait.mjs`), `isHumanRequest` / `currentOwnerResult` (`server/delegation-receipts.mjs`) | Extends shared list/session truth and cache stamps; retains real requests across compaction, excludes machine inputs, and projects the existing Supervisor ledger without adding a scheduler. Existing follow-through admission owns continuation delivery. Covered by `tests/owed-helper-work.test.ts` and `tests/helper-continuation-evidence.test.ts`. |
| Locked Claude cooldown admission | `confirmedClaudePoolExhaustion` (`server/claude-cooldown-bridge.mjs`) at the existing main durable run-queue launch (`server/service.mjs`) | REUSE the host dashboard account broker and Claude connector, EXTEND their cheap read-only `/model-cooldowns` → `/api/model-cooldowns` bridge with a fresh secret-free projection of exact per-model `model_cooldowns` across every raw grant (before display mirror folding), and EXTEND shared queue admission only before first dispatch. A fresh complete two-grant snapshot may fail a saved/idempotent locked turn; stale, reset, missing, alternate-grant or ambiguous evidence goes to stock Hermes. No credentials enter Agent Service. `tests/claude-cooldown-bridge.node.mjs` covers HTTP admission, replay/restart/retry and container topology; `tests/test_provider_accounts.py` covers host projection. |
| Live run events for model-locked turns | `RunEventLog` (`server/run-event-log.mjs`), `LockedRunBridge.events` (`server/locked-run-bridge.mjs`) | Hermes serves `/v1/runs/<id>/events` only for `POST /v1/runs` runs; locked turns run in `chat/stream`, so the bridge records those frames in native event names and the service serves them for queued and direct reads. Reuse it for any other stream-admitted run instead of polling. Covered by `tests/locked-run-events.test.ts` and `tests/run-event-log.node.mjs`. |
| Ready list projection scheduling | `projectListSlices` / `createJoinedListCheck` (`server/session-list-cache.mjs`), `projectSessionListCore` (`server/service.mjs`) | EXTEND the existing list projector: yield every 20 rows, carry the global 48-row preview cap and join self-checks. REUSE canonical truth/helper/supervisor readers without cross-reader evidence caching; filter relevant heavy jobs before transcript reads. No UI, endpoint or dependency change. Covered by `tests/ready-thread-speed.node.mjs`, `tests/owned-open-work.test.ts`, existing cache and per-runtime parity suites. |
| Hermes import host-shared paths | `host_shared_paths` / `return_host_shared` / `restore_host_shared` (`ops/agent-runtime/hermes_import.py`) | NEW: host app data and runtimes (`data/apps`, `bin`, `hermes-agent`, `venvs`, `tools`, `node`, `installs`, `runtime`, `vendor`, `lsp`, plus owner-approved additions) stay at their host paths on a move import; EXTEND the existing writer census and journal/undo with write-ahead inode receipts. Additions that name agent state, secrets, SQLite sidecars, symlinked parents or hard-linked files are refused. No UI component. Covered by `tests/test_hermes_import.py` and `scripts/test-hermes-import.mjs`. |
